1次元力学系 （第2-3章）

基本形式

ẋ = f(x)

1変数の常微分方程式。軌道は数直線上の点の流れとして表現。

固定点の解析

概念 定義・条件 意味
固定点 x* f(x*) = 0 時間発展しない点
安定 f'(x*) < 0 近傍の軌道が収束
不安定 f'(x*) > 0 近傍の軌道が発散
半安定 f'(x*) = 0 片側から安定、片側から不安定

ポテンシャル関数（勾配系）

ẋ = −dV/dx
  • V(x) の極小点 → 安定固定点
  • V(x) の極大点 → 不安定固定点
  • 軌道は常に V を減少させる方向に流れる
1次元系の特徴：
  • 軌道は交差しない（一意性）
  • 振動は起きない
  • カオスは起きない
  • 固定点に収束するか、±∞に発散するかのみ

1次元の分岐 （第3章）

分岐（bifurcation）：パラメータの変化により、系の定性的な振る舞いが変化する現象。

サドルノード分岐
ẋ = r + x²

r < 0: 2固定点（安定・不安定）
r = 0: 合流して消滅
r > 0: 固定点なし

固定点の生成・消滅

トランスクリティカル分岐
ẋ = rx − x²

x* = 0 と x* = r が
r = 0 で交差し、
安定性を交換

固定点は消滅しない

ピッチフォーク分岐（超臨界）
ẋ = rx − x³

r < 0: x* = 0 のみ（安定）
r > 0: x* = 0（不安定）
　　　x* = ±√r（安定）

対称性のある系

ピッチフォーク分岐（亜臨界）
ẋ = rx + x³

r < 0: x* = ±√|r|（不安定）
r > 0: x* = 0（不安定のみ）

危険！突然のジャンプ

分岐図の読み方

表記 意味
実線 安定固定点の軌跡
破線 不安定固定点の軌跡
分岐点 線が合流・分岐する点
正規形（Normal Form）： 分岐点近傍での系の本質的な振る舞いを捉えた最も単純な形式。 実際の系は座標変換により正規形に帰着できる。

2次元力学系 （第5-7章）

基本形式

ẋ = f(x, y),   ẏ = g(x, y)

または行列形式（線形系）：ẋ = Ax

固定点の分類（線形化）

固定点 (x*, y*) でのヤコビ行列：

J = [∂f/∂x, ∂f/∂y; ∂g/∂x, ∂g/∂y](x*, y*)

固有値 λ1, λ2 を求める：det(J - λI) = 0

τ = tr(J) = λ₁ + λ₂,   Δ = det(J) = λ₁λ₂
固定点の種類 固有値の条件 τ, Δ の条件 安定性
安定ノード λ₁, λ₂ < 0 (実数) τ < 0, Δ > 0, τ² > 4Δ 漸近安定
不安定ノード λ₁, λ₂ > 0 (実数) τ > 0, Δ > 0, τ² > 4Δ 不安定
安定スパイラル Re(λ) < 0 (複素) τ < 0, τ² < 4Δ 漸近安定
不安定スパイラル Re(λ) > 0 (複素) τ > 0, τ² < 4Δ 不安定
サドル点 λ₁ < 0 < λ₂ Δ < 0 不安定
中心点 (Center) 純虚数 ±iω τ = 0, Δ > 0 安定（非漸近的）

相平面の要素

ヌルクライン (Nullclines)

  • x-ヌルクライン: f(x,y) = 0 の曲線（軌道は垂直に横切る）
  • y-ヌルクライン: g(x,y) = 0 の曲線（軌道は水平に横切る）
  • 交点 = 固定点

多様体 (Manifolds)

  • 安定多様体 Ws: t→∞ で固定点に収束する軌道の集合
  • 不安定多様体 Wu: t→-∞ で固定点に収束する軌道の集合
  • サドル点では両方が存在

リミットサイクル

孤立した閉軌道。近傍の軌道が渦巻きながら近づく（または離れる）。

Poincaré-Bendixson 定理

平面上の有界な領域 R に閉じ込められた軌道で、R 内に固定点を含まないものは、 リミットサイクルに漸近する（または自身がリミットサイクル）。

→ 2次元連続系ではカオスは起きない

Bendixson-Dulac 判定法

単連結領域 D で ∂(ρf)/∂x + ∂(ρg)/∂y が符号一定（≠0）ならば、D 内に閉軌道は存在しない。

ρ(x,y) は適当な正の関数（Dulac関数）。

指数理論 (Index Theory)

IC = (1/2π) ∮C dφ
対象 指数
ノード、スパイラル、中心点 +1
サドル点 -1
閉曲線内の指数の和 閉曲線の指数
リミットサイクル内 必ず +1

2次元の分岐 （第8章）

固定点の分岐

1次元と同様に、サドルノード、トランスクリティカル、ピッチフォーク分岐が起こりうる。

Hopf 分岐

固定点からリミットサイクルが生まれる分岐。

超臨界 Hopf 分岐 (Supercritical)
ṙ = μr − r³, θ̇ = ω

μ < 0: 安定スパイラル
μ = 0: 分岐点
μ > 0: 不安定スパイラル + 安定リミットサイクル

ソフトな遷移

亜臨界 Hopf 分岐 (Subcritical)
ṙ = μr + r³ − r⁵, θ̇ = ω

μ < 0: 安定スパイラル + 不安定サイクル
μ = 0: 分岐点
μ > 0: 不安定スパイラル

突然のジャンプ（ハード遷移）

大域分岐（閉軌道の分岐）

サドルノードサイクル分岐 (SNLC)

2つのリミットサイクル（安定・不安定）が合流して消滅

Hopf分岐の閉軌道版

ホモクリニック分岐

リミットサイクルがサドル点に接触

周期 T → ∞（対数的発散）

サイクルがサドルの「ループ」に

SNIPER / SNIC 分岐

Saddle-Node on Invariant Circle

周期 T ∝ 1/√|μ - μ_c|

ボトルネック効果

ヘテロクリニック分岐

リミットサイクルが複数のサドル点を結ぶ軌道に

まれだが重要

周期スケーリング

分岐の種類 周期 T の発散
SNIPER (SNIC) T ∝ 1/√|μ - μ_c|
ホモクリニック T ∝ -ln|μ - μ_c|
Hopf T → 2π/ω（有限）

ヒステリシス

亜臨界分岐やサドルノード分岐を含む系では、パラメータを上げるときと下げるときで異なる経路をたどる。

例：ジョセフソン接合（8.5節）

離散写像とカオス （第10章）

1次元写像

xn+1 = f(xn)

固定点の安定性

条件 結果
|f'(x*)| < 1 安定
|f'(x*)| > 1 不安定
|f'(x*)| = 1 臨界（分岐点）

周期 n 軌道

f を n 回合成した写像 fn の固定点。安定条件：

|（fn）'(x*)| = |f'(x₁)·f'(x₂)·...·f'(x_n)| < 1

ロジスティック写像

xn+1 = r·xn(1 − xn)
r の範囲 振る舞い
0 < r < 1 絶滅（x → 0）
1 < r < 3 固定点 x* = (r-1)/r に収束
3 < r < 3.449... 周期2軌道
3.449... < r < 3.5699... 周期 2n（周期倍分岐カスケード）
r > r∞ ≈ 3.5699... カオス（周期窓あり）

Feigenbaum 定数と普遍性

δ = limn→∞ (rn - rn-1) / (rn+1 - rn) = 4.669201609...

この定数は普遍的：すべての単峰写像（unimodal map）で同じ値。

繰り込み群の考え方で説明される（10.7節）。

Lyapunov 指数

λ = limn→∞ (1/n) Σi=0n-1 ln|f'(xi)|
λ の値 意味
λ < 0 周期的アトラクター
λ = 0 分岐点、準周期
λ > 0 カオス（初期値鋭敏性）

カオスの特徴

  • 初期値鋭敏依存性：近い初期値が指数関数的に離れる
  • 非周期性：同じ状態に戻らない
  • 決定論的：ランダムではない、方程式に従う
  • 有界性：軌道は有界領域に留まる
注意：2次元連続系ではカオスは起きない（Poincaré-Bendixson）。 しかし離散系（写像）では1次元でもカオスが可能。

重要定理一覧

存在と一意性定理

f が C1 級ならば、初期値問題 ẋ = f(x), x(0) = x₀ の解は局所的に存在し一意。

帰結：軌道は交差しない。

Hartman-Grobman 定理

双曲型固定点（Re(λ) ≠ 0）の近傍では、非線形系の軌道は線形化 ẋ = Jx の軌道と位相的に同値。

意味：線形化で固定点の定性的な振る舞いがわかる。

注意：中心点（Re(λ) = 0）には適用不可。

Poincaré-Bendixson 定理

平面上の閉じた有界領域 R に閉じ込められた軌道が R 内に固定点を含まないとき、その軌道はリミットサイクルに漸近するか、自身がリミットサイクル。

帰結：2次元連続系ではカオスは起きない。

Bendixson-Dulac 判定法

単連結領域 D で div(ρF) = ∂(ρf)/∂x + ∂(ρg)/∂y が符号一定（≠0）ならば、D 内に閉軌道は存在しない。

使い方：適切な ρ(x,y) > 0 を見つける。

Liapunov の安定性定理

固定点 x* の近傍で V(x) > 0 (x ≠ x*), V(x*) = 0, V̇ ≤ 0 を満たす関数 V が存在するなら、x* は安定。 V̇ < 0 なら漸近安定。

指数定理

閉曲線 C が固定点を含まないとき、C の指数は C 内部の全固定点の指数の和に等しい。

帰結：リミットサイクル内には指数の合計が +1 になる固定点がある。

Hopf 分岐定理

パラメータ μ の変化で固有値 λ(μ) = α(μ) ± iω(μ) が虚軸を横切るとき（α(0) = 0, dα/dμ ≠ 0, ω(0) ≠ 0）、 固定点からリミットサイクルが分岐する。
