Feigenbaum の普遍性（10.6節）

δ = 4.669201609...（Feigenbaum定数）

驚くべきことに、この定数は写像の詳細によらず普遍的：

  • ロジスティック写像: x → rx(1-x)
  • sin写像: x → r·sin(πx)
  • 任意の単峰写像（unimodal map）

これは繰り込み群の考え方で説明される（Strogatz 10.7節）
